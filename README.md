# MISS - Miss总结插件

一个 SillyTavern（酒馆）UI 扩展：摘要标签抓取 + AI 记忆总结 + 楼层隐藏注入。

## 安装

SillyTavern → 扩展（Extensions）→ 安装扩展 → 输入仓库地址：

```
https://github.com/nai040720-svg/MISS
```

## 功能

### 入口
聊天框左侧工具栏（扩展菜单）点击 **Miss总结插件**，右侧扩展面板自动展开并定位到插件。

### 初始设置
- **摘要标签**：填写标签名（如 `summary`），插件自动抓取聊天气泡中 `<summary>...</summary>` 包裹的内容
- **绑定预设**：列出所有 SillyTavern 预设，可选择绑定；总结时临时切换到该预设，完成后自动恢复（不选则不绑定）
- **保存初始设置**：填写名称 → 点击保存（弹窗确认）→ 保存后出现在下方选择栏，切换即立刻应用整套配置，支持多套配置与删除

### 记忆总结
- **记录**：细滚动条列表，仅显示摘要标题；点击展开详情；右上角**编辑模式**可修改内容并覆盖写回聊天/元数据
- **总结设置**：
  - 实时显示当前「预设 + 聊天记录 + 提示词」总 Token 数（随角色卡切换实时更新）
  - **Token 总结**：总 Token 达到设定值自动总结
  - **楼层总结**：新楼层数达到设定值自动总结
  - **隐藏楼层**：仅保留最近 N 楼发送给 AI，更早楼层自动隐藏（标记为系统楼层），改为注入记忆摘要
  - 可自定义总结提示词，可手动触发「立即总结」

## 主题适配

界面完全绑定 SillyTavern 主题变量（`--SmartThemeQuoteColor` / `--SmartThemeBodyColor` / `--SmartThemeBlurTintColor` / `--SmartThemeFont` 等），自动跟随用户当前主题配色。

## 数据存储

| 数据 | 位置 |
|---|---|
| 标签 / 绑定预设 / 阈值 / 已保存设置 | `extension_settings`（全局设置） |
| AI 摘要记录 | 聊天元数据（随聊天/角色卡走） |
