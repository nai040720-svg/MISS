# MISS - Miss总结插件

SillyTavern 扩展：统一整理聊天楼层、摘要标签正文和大总结，并调用 AI 生成记忆。

## 安装

在 SillyTavern → 扩展 → 安装扩展中输入：

```text
https://github.com/nai040720-svg/MISS
```

## 记录与总结

1. 在“初始设置”填写摘要标签，例如 `summary`；支持多个标签。
2. 点击“抓取无标签正文”后，插件按楼层建立统一记录：
   - 有摘要标签的楼层：只取标签内正文；
   - 没有标签的楼层：取该楼层完整正文；
   - 同一楼层不会同时生成两份记录，多标签楼层不会再被当成无标签正文。
3. 记录列表仅为观看方便按楼层倒序显示（数字大的在上面）；发送给 AI 时始终按楼层正序。
4. “总结时发送全文”会发送当前未隐藏楼层的统一正文。已经自动隐藏的楼层视为已总结，不会被绕过；标签正文和无标签正文不会重复。
5. 总结请求顺序为：

```text
破限提示词 → 摘要信息 → 总结提示词
```

标题只用于界面展示，不会代替正文发送。“重新总结”会读取当前未隐藏的统一记录，不会只发送第一次总结的内容。

## 界面

- “总结设置”可折叠；自动总结、自动隐藏、发送全文和立即总结按钮保持在折叠条外。
- “大总结内容”单独作为摘要子分组，可重新总结，也可删除全部大总结及其世界书条目。
- 编辑无标签记录只修改对应聊天消息；编辑标签记录只替换对应消息中的首个匹配正文。

## 自动隐藏

- 勾选自动隐藏后，总结完成会立即隐藏已经总结的旧楼层。
- 之后再次总结时，已隐藏楼层不会发送；开启全文模式也只会发送未隐藏部分。
- 关闭隐藏规则后，插件会恢复由插件隐藏的消息。

## 世界书与数据

总结结果会写入当前聊天绑定的世界书。摘要记录、隐藏状态和全文模式保存在当前聊天元数据；标签、阈值和 API 配置保存在扩展设置中。

## API

副 API 支持 OpenAI 兼容的 Chat Completions 接口。请不要在共享环境中保存或提交敏感配置。
