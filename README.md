# MISS - Miss总结插件

SillyTavern 扩展：统一整理聊天楼层、摘要标签正文和大总结，并调用 AI 生成记忆。

## 安装

在 SillyTavern → 扩展 → 安装扩展中输入：

```text
https://github.com/nai040720-svg/MISS
```

## 记录与总结

1. 在“初始设置”填写摘要标签，例如 `summary,小冰块,Anti-truncation`；支持中文、英文、连字符和多个标签，也可粘贴完整的 `<标签>...</标签>` 或 `[标签]...[/标签]`。“去除正文多余的包裹内容”同样支持这些标签名，两种括号形式都会连内部内容一起删除；不要把需要保留的摘要标签填进去。
2. 点击“抓取无标签正文”后，插件按楼层建立统一记录：
   - 有摘要标签的楼层：只取标签内正文；
   - 没有标签的楼层：取该楼层完整正文；
   - 同一楼层不会同时生成两份记录，多标签楼层不会再被当成无标签正文。
3. 记录列表仅为观看方便按楼层倒序显示（数字大的在上面）；发送给 AI 时始终按楼层正序。
   无标签正文的标题取正文首行，并显示对应楼层；抓取状态保存在当前聊天中。
4. “总结时发送全文”会发送当前未隐藏楼层的纯净剧情正文与摘要正文；摘要正文只出现一次。取消“是否总结用户输入”后，所有总结模式和预览均跳过用户楼层。已经隐藏的楼层不会参与新的立即总结。预览按钮可查看本次将发送给 AI 的正文。
5. 总结请求顺序为：

```text
破限提示词 → 摘要信息 → 总结提示词
```

标题只用于界面展示，不会代替正文发送。每条大总结保存本次涉及的楼层编号，供单独重新总结使用。
记录预览、总结和单条重新总结共用清理流程：先运行 SillyTavern「对提示词生效」的正则，再删除自定义包裹块、代码块、脚本/样式、美化标签和独立的字数统计行，最后提取摘要并去重。普通展示标签只去掉外壳、保留文字；自定义删除标签会连内部文字一起删除。清理不会修改原聊天，编辑模式仍显示原文。无法加载酒馆正则引擎时，记录不会显示未过滤原文，总结也会中止。

## 界面

- “总结设置”可折叠；自动总结、自动隐藏、发送全文、是否总结用户输入和立即总结按钮保持在折叠条外。
- “补总结隐藏楼层”列出已隐藏且未被大总结覆盖的楼层。可全选、清空、按楼层范围选中或逐条勾选；预览后总结所选楼层。补总结会恢复楼层原有的隐藏状态，不改变正常总结的起点。
- “大总结内容”中每条摘要右侧都有“重新总结”和“删除”。重新总结只处理该条覆盖的楼层，临时解除这些楼层的隐藏状态，完成或失败后恢复原状态；当前“发送全文”勾选项决定重总时使用全文还是摘要记录。
- 删除只移除选中的大总结，并同步更新插件维护的世界书摘要；不再被其他大总结覆盖的楼层会恢复显示。
- 编辑无标签记录只修改对应聊天消息；编辑标签记录只替换对应消息中的首个匹配正文。

## 自动隐藏

- 勾选自动隐藏后，总结完成会立即隐藏已经总结的旧楼层。
- 之后再次总结时，已隐藏楼层不会发送；开启全文模式也只会发送未隐藏部分。
- 关闭隐藏规则后，插件会恢复由插件隐藏的消息。

## 世界书与数据

总结结果会写入当前聊天绑定的世界书。摘要记录、抓取状态和隐藏状态保存在当前聊天元数据；全文模式、标签、阈值和 API 配置保存在扩展设置中。

## API

副 API 支持 OpenAI 兼容的 Chat Completions 接口。流式连接提前断开、返回长度上限、空结果或请求失败会给出错误弹窗；若副 API 失败但主 API 成功接管，也会提示。主 API 的 `generateQuietPrompt` 只返回文本，无法读取提供方的截断原因。请不要在共享环境中保存或提交敏感配置。
