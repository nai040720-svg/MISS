# MISS - Miss总结插件

SillyTavern UI 扩展：抓取聊天中的摘要标签正文，调用 AI 生成记忆摘要，并按设置隐藏旧楼层。

## 安装

在 SillyTavern → 扩展 → 安装扩展中输入：

```text
https://github.com/nai040720-svg/MISS
```

## 核心流程

1. 在“摘要标签”中填写标签名，例如 `summary`。
2. 插件从聊天消息中提取 `<summary>...</summary>` 内的完整正文。
3. 总结请求按以下顺序发送：

```text
破限提示词 → 摘要标签完整正文 → 总结提示词
```

4. 标题只用于插件界面列表显示，不会作为总结输入。
5. “重新总结”会重新读取当前聊天中的全部摘要标签正文，不依赖旧 AI 摘要。

## 总结与隐藏

- **Token 总结**：达到设置的 Token 阈值后自动总结。
- **楼层总结**：新的摘要标签记录达到设置数量后自动总结。
- **保留最近 N 个角色楼层**：隐藏更早楼层，并注入已生成摘要。
- **自动隐藏楼层**：隐藏更早楼层，不注入摘要，依赖世界书中的摘要。
- 关闭隐藏规则后，插件会恢复由插件隐藏的消息。

## 世界书

总结结果会写入当前聊天绑定的世界书。插件维护一个摘要条目，重复总结会更新该条目，避免旧摘要重复注入。

## API

副 API 当前支持 OpenAI 兼容的 Chat Completions 接口。API 密钥会写入 SillyTavern Secrets 供请求使用，同时当前配置仍会保存在扩展设置中以支持重启后复用；请不要在共享环境中保存或提交敏感配置。

## 数据存储

| 数据 | 位置 |
|---|---|
| 标签、阈值、API 配置 | `extension_settings` |
| 摘要记录、隐藏状态 | 当前聊天元数据 |
| 世界书摘要 | 当前聊天绑定的世界书 |
