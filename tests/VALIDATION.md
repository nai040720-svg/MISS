## 明确局限

- 浏览器页面端到端测试未运行：环境拒绝 Chromium 所需的 Unix socket，云浏览器拒绝 localhost。没有绕过这些限制
- Node 通过 ST context/模块适配器执行插件；ST 服务、HTTP 路由、mock 服务和磁盘持久化是真实运行。不能将它描述为完整前端浏览器通过
- 仅验证上述 ST 版本；没有声明兼容所有历史版本
- Token 数不是完整 ST prompt 组装器的精确复刻，未覆盖所有预设、世界书或多模态开销
- 明确目标保存防止聊天错写，仍不是跨 ST 其他功能的数据库事务锁。网络失败和并发外部世界书编辑不能获得原子事务保证
- 已有手动隐藏或旧版无归属标记的消息保持原样；歧义旧世界书条目不擅自删除
- 原生非 OpenAI API 格式被明确拒绝，而不是错误发送；副 API 设置仍会保存用户输入的密钥，应保护设置文件
